# Personal content as desktop applications

Home is the personal-content entry point and remains the first focused window. Its
client behaves as an Explorer folder: a category tree changes the folder, one click
selects an item and updates a preview, and double-click, Enter or Open activates
the selected destination. The current folder, selection and preview are visible
without scrolling through a portfolio landing page. A compact toolbar exposes
Back, Up, Open and Properties; a location field and status bar report state.

About is a Properties sheet. General contains identity and current work. Projects
uses one list and one detail area rather than eight repeated cards. Journey,
Honors, Photos and Contact retain their existing authored records and stable hashes.
The footer provides Home and Close. Project hashes continue to select their exact
record, and normal history navigation restores the selected tab or folder.

General also provides three editorial paths through these same records. Projects
adds text/technology filters and stable sorting without creating duplicate project
pages. A pure browsing model owns the selection rules; explicit guide links reveal
their destination and transfer keyboard focus. Very short clients use one document
scroller so the minimum desktop window keeps its tools and records reachable.
Contact offers a downloadable UTF-8 vCard and a copy-address control with a native
selectable-text fallback. All fields come from the existing public profile.

Controls use the shared hybrid components and English labels. Authored Chinese
text uses the native 12 px MHK CJK face. Original photographs remain the default;
the existing image-presentation preference controls optional pixel treatment.
No project facts, media originals, public routes or legacy bridge keys change.

The global personal-site link bar is a standalone/no-JavaScript fallback, hidden
inside managed windows. Each application supplies only navigation relevant to its
own task. Anchors keep real destinations, so no-JavaScript and modified-click
navigation remain available. JavaScript adds selection and preview only to marked
Explorer controls. Every listener and temporary menu is disposed with its page.

Acceptance covers single-click selection without navigation, keyboard and mobile
Open, exact project deep links, Back/Up, Properties tabs, original-image launch,
Close back to the existing desktop, and the standalone/no-JavaScript document.
