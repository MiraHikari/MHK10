# MHK10

MHK10 是 MiraHikari 的个人桌面与站点。它的故事、应用和本地文档共享桌面体验，但个人内容不受虚构故事权限影响。

## Language

**桌面会话**：从启动到退出的一次 MHK10 使用过程，包括打开的窗口、当前仪表和正在编辑的文档。
_Avoid_: 系统存档、窗口

**个人内容**：MiraHikari 发布的介绍、项目、图片和文章。访客可以阅读，不能通过桌面修改原件。
_Avoid_: 我的文档、训练数据

**阅读笔记**：访客 notebook 中按稳定 id 保存的引用、文字与定位信息。桌面的 offset
是全文 UTF-16 偏移；通用站的 block 是块索引及块内范围。定位失效不会删除笔记。
_Avoid_: DOM 高亮数组、正文内容

**阅读偏好**：两种呈现共同保存的 Reader 选项。没有保存宽度时默认 comfortable；
通用站把 narrow 显示为紧凑档。进度、笔记和偏好分别订阅，各自更新。
_Avoid_: 桌面专属默认、滚动快照

**我的文档**：访客在自己的浏览器中创建或保存的本地文件集合。
_Avoid_: 个人内容、站点文件

**剧情检查点**：通过主动选择推进并可以重放的故事进度。重放剧情不等于删除访客文档。
_Avoid_: 文件备份、系统权限

**基准风险**：故事当前阶段对应的 P(doom) 起始值。
_Avoid_: 当前风险

**当前风险**：当前会话仪表实际显示的 P(doom) 数值，可以在剧情阶段之间按规则调整。
_Avoid_: 基准风险、剧情进度

**会话副本**：当前仍可使用、但尚未成功保存到浏览器持久存储的文档副本。
_Avoid_: 已保存文件、备份

**另存为**：将编辑内容保存到用户选择的名称和文件夹；覆盖已有文件需要明确确认。
_Avoid_: 导出

**导出**：将文档或文档集合下载到浏览器之外，由用户保管。
_Avoid_: 另存为、本地保存

**注册事实 (registration facts)**：应用向桌面注册自身所需的全部纯数据声明（标识、路由、窗口几何、菜单归属、文件关联、别名等）。每个 Canvas 应用的注册事实保存在实现旁的 `src/lib/apps/<feature>/<id>.registration.ts` sidecar 中，是这些事实的唯一作者侧来源；目录快照由其生成。
_Avoid_: 配置项、元数据（泛称时）、app manifest

**目录快照 (catalog snapshot)**：由 `scripts/generate-app-catalog.mjs` 从全部注册事实 sidecar 生成的零导入数据文件（`app-catalog.generated.ts`），供构建期与离线脚本消费；手写包装模块保留 `CATALOG_ORDER` 排序表与 `NON_CANVAS_APPS` 非 canvas 种子。快照与注册事实失配由新鲜度门禁测试拦截。
_Avoid_: 手写目录、中心注册表
