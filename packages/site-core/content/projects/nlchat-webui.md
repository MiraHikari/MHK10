面向串口调试场景的聊天式 Web 工具：

- 支持波特率、数据位、停止位、校验位与硬件流控制配置
- 支持 Text、Hex、ANSI 多种数据显示格式与智能分包
- 提供命令历史、日志复制与导出等常用调试能力
