面向校园池塘、社区湖泊和城市景观水体的无人水面清洁原型：

- 以约 2000 元的消费级硬件实现低成本水质巡航与漂浮垃圾清理
- 通过 HuskyLens 识别垃圾，结合浊度等传感器、差速推进和舵机打捞机构
- 使用 MQTT 上报遥测数据，并由 React 数据面板提供状态可视化与远程控制
